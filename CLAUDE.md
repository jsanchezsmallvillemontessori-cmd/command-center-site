# Working rules for AI chats in this project

## When Jason types "sync" (alone)

No questions, no changes to the project. Works the same on his Mac and in a cloud chat.
1. Get the latest copy: `git fetch origin` and bring this folder up to the latest `main`, only when the folder has no unsaved work. Never push.
2. Read the journals that exist here, newest parts first: the build log (`BUILD_LOG.md` or `docs/DEVELOPMENT-LOG.md`); the open-items list and status page; the notes (`wiki/`, `docs/wiki/`); the lessons (`LEARNINGS.md`, `docs/LESSONS.md`); the shared-wiki copy (`wiki-snapshot/`, or on the Mac `~/.hermes/wiki/README.md` and this project's page); then this file's rules.
3. On the Mac only: run `wiki-sync`.
4. Reply in plain words, under 80 words: one line "synced to <latest change>, <date>", up to 3 bullets on what changed and what is open or waiting on Jason, and one question only if he must decide. Name any journal that is missing; never invent one.
